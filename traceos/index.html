01 / WHAT IT DOES

A connected workspace for the whole picture.

TraceOS is a live web application with organization-scoped access and a project, task, and activity model. The MCP adapter exposes only existing read operations; it does not invent machine metrics or alerts.

01 — PROJECTS

Project health

Current progress, overdue task counts, and status from TraceOS project records.

02 — KNOWLEDGE

Semantic search

Search the caller’s authorized TraceOS records and retrieve matching excerpts.

03 — ACTIVITY

Daily digest

Read the authenticated account’s daily activity summary from TraceOS.

04 — SERVICE

Application health

Read the API’s health response and AI-provider configuration status.

02 / INTEGRATION

TraceOS stays the source of truth.

The adapter forwards each caller’s TraceOS bearer token to the existing API. TraceOS performs user, organization, and role checks on every data operation.

03 / AVAILABLE MCP TOOLS

Read-only by design.

traceos_health

Reads the live TraceOS API health response. Requires a valid TraceOS access token.

project_health

Reads project progress and overdue counts visible to the authenticated user.

search_traceos

Semantic search with a bounded query and a maximum of 25 results.

daily_digest

Reads the caller’s authorized daily activity digest.

Security: Every tool call requires a TraceOS bearer token. API roles and organization boundaries remain enforced by TraceOS. The adapter has no write, shell, filesystem, or arbitrary URL tools. No bearer token belongs in this public page.
